# Security Policy

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report privately via [GitHub's private vulnerability reporting](https://github.com/justinstimatze/lucida/security/advisories/new),
or email **justin@justinstimatze.com** with subject line `[lucida] Security`.

You can expect an acknowledgement within 48 hours and a fix or
mitigation timeline within 7 days for confirmed issues.
