# Gibson reference frames

Source: Hackers (1995) Gibson supercomputer scene, https://youtu.be/IESEcsjDcmM (and stills via https://scifiinterfaces.com/2023/12/11/hackers/).

These are the canonical references for tuning the `mixed3d` layout / `hackers` theme. Filenames are descriptive so I can grab the right one without re-viewing.

| File | What it shows | Useful for |
| --- | --- | --- |
| `canyon_flythrough.png` | Wide canyon flythrough — multiple cyan towers along a long aisle | Skyline density, fog, overall canyon feel |
| `tower_face_labels.png` | Close-up vertical pink labels on tower face (COMPANY STATUS, EXPLOR ENVT, GARBAGE) | "6 vertical columns of data per face" rule, label color/font |
| `tower_glass_closeup.png` | Cyan tower glass closeup, data patterns on faces | Tower transparency, edge silhouette, internal scanlines |
| `tower_bases_low_angle.png` | Low-angle bases meeting floor, soft glow at junction, purple accents | Base glow / pad / cone diffuseness, floor accent traces |
| `monitor_directory_listing.png` | CRT showing the directory listing | Pink/red caps label typography, right-justified layout |
| `tower_danger_mode.png` | Red-orange tower under danger phase lighting | Danger-mode palette, internal circuit visibility |
| `ops_room_wall.png` | Operations room with people watching the monitor wall | Scale reference (humans next to towers); not for canyon tuning |
